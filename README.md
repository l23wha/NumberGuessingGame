# 🎯 CLI Number Guessing Game (Node.js)

A fun, interactive command-line-based **Number Guessing Game** written in JavaScript (Node.js). Test your logic and luck by guessing a randomly generated number between 1 and 100 within a limited number of attempts!

---

## 🚀 Features

* 🎮 **Interactive CLI Interface:** Built using Node.js native `readline` module.
* 🎯 **Multiple Difficulty Levels:** Choose between Easy, Medium, or Hard modes.
* ⏱️ **Real-Time Tracking:** Accurately measures the total time taken (in seconds) to finish the game using JavaScript timestamps.
* 💡 **Smart Hint System:** Stuck on a guess? Type `hint` to get clues (e.g., Even/Odd, Multiples) at the cost of 1 attempt.
* 🛡️ **Robust Input Validation:** Ignores invalid text entries without wasting your remaining attempts.
* 🔄 **Replay Feature:** Play as many rounds as you want without restarting the app.

---
